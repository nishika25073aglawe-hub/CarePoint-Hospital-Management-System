# CarePoint – Hospital Management System

**A Database-Driven Web Application for Hospital Management**

## About the Project

CarePoint is a web-based Hospital Management System developed as part of an academic DBMS project. It aims to simplify hospital operations by providing a single platform to manage patients, doctors, appointments, ambulances, beds, wards, and medical records.

The project uses a MySQL database connected to a web application through a Node.js and Express.js backend.

## Project Overview

Managing hospital information manually can be time-consuming and difficult. CarePoint helps organize hospital data in one place, making it easier to store, update, and retrieve information.

The project also demonstrates the practical use of database concepts such as relational tables, primary keys, foreign keys, SQL queries, and table relationships.

## Features

### 1. Dashboard

- Provides access to different hospital management modules.
- Displays an overview of hospital operations.

### 2. Doctor Management

- Add, view, update, and delete doctor details.
- Maintain doctor information and specializations.

### 3. Patient Management

- Register new patients.
- View and manage patient information.

### 4. Appointment Management

- Book appointments between patients and doctors.
- View appointments and manage their status.

### 5. Ambulance Management

- View ambulance details.
- Track and update ambulance availability.

### 6. Beds and Wards Management

- View hospital wards and beds.
- Monitor available and occupied beds.

### 7. Medical Records

- Store patient diagnoses and medical notes.
- Link medical records with patients and doctors.

### 8. Medical Reports

- Add and view patient medical reports.
- Store report types and details.

## Database Design

The project uses a relational MySQL database named `hospital_management`.

The database is designed to store different types of hospital information, including:

- Patient and doctor details
- Hospital departments
- Doctor schedules
- Appointments and appointment slots
- Medical records and reports
- Prescriptions and medicines
- Wards and beds
- Ambulance information

### DBMS Concepts Used

- Relational Database Model
- Primary Keys and Foreign Keys
- Referential Integrity
- Database Normalization
- SQL Queries (INSERT, SELECT, UPDATE, DELETE)
- Joins
- Auto Increment

## System Architecture

CarePoint follows a three-tier architecture:

1. **Presentation Layer:** HTML, CSS, and JavaScript provide the user interface.
2. **Application Layer:** Node.js and Express.js handle requests and backend operations.
3. **Database Layer:** MySQL stores and manages hospital information.

The frontend communicates with the backend through API requests, and the backend interacts with the MySQL database to perform operations.
